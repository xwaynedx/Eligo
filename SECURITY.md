# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/xwaynedx/Eligo/security/advisories/new). Do not file a public issue for a security problem.

Eligo registers as a default-browser handler and receives URLs from arbitrary source applications, so issues in URL handling and routing are real attack surface and are taken seriously.

## What to expect

- Reports are read by the maintainer. Expect an initial response within about a week.
- If a report is confirmed, a fix is prepared before any public disclosure, and the reporter is credited in the release notes unless they ask otherwise.

## Out of scope

- General bugs and feature requests: [open a GitHub issue](https://github.com/xwaynedx/Eligo/issues).
- Usage questions and troubleshooting: see [docs/support.md](docs/support.md).
